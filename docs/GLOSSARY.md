# Glossary: the plain names used everywhere (tidy pass, Agent 1)

One name per idea, used in every label, notice, tooltip and doc page that a user reads. The technical name stays
in the places listed in the last column (details drawers, file names, URLs, the API, developer docs). The
"tooltip" column is the text of the "?" tooltip the later agents attach to the term where it first appears on a
screen. Where a variant appears today is listed so the rename can be done item by item (`grep` the variant in
`static/` and `docs/`).

Rules that apply to every term:

- The first time a term appears on a screen it carries the "?" tooltip; later uses on the same screen do not.
- A technical name may appear **after** the plain name in parentheses inside a details drawer, never alone.
- File names are never renamed (`seedance-input.mp4` stays), but a download link says the plain name first:
  "Prepared clip (seedance-input.mp4) ↓".
- Prices are written "about $2.15"; "free" is written "free"; never "estimate", "cost gate", "confirm_cost".

## 3. Words that are banned from the UI after the tidy pass

`job`, `branch` (verb or noun), `child`, `parent`, `chain`, `stage rack`, `tool` (use method), `slot`, `plate`,
`fence`, `wand`, `propagate`, `landmarks` (outside file names), `tracking` (use found / lost), `fingerprint`,
`session`, `pending` (use unsaved), `HD`, `finalize`, `upgrade`, `complete the draft`, `estimate`, `confirm_cost`,
`provider` (use generator / depth model), `Depth + SAM`, `Seedance · Edit` / `Omni`, `legacy`, `kit`, `Lab`,
`depth` as the name of a UI level, `Quick view`, `Studio`, `input doctor`, `beats` (outside the prompt text),
`control video`, `seedance-input` (outside file names). A later agent greps for each before closing the pass.
